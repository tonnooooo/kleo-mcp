# Third-party components and asset provenance

The original Keou code and documentation are distinct from the upstream components below. Their names do not imply endorsement. Preserve applicable upstream notices when distributing their files.

## Files actually included in this folder

| File / content | Source and notice |
|---|---|
| engine/assets/font.ttf | Manrope by the Manrope Project Authors. SIL Open Font License 1.1; full text in licenses/Manrope-OFL.txt and beside the font. |
| engine/assets/world.json | Natural Earth 1:110m land data. Public domain under [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/). Made with Natural Earth. |
| Example SVG diagrams | Original Keou explanatory artwork. Galaxy and equal-mass orbit diagrams use NASA factual references listed in the example SOURCES.md. No NASA imagery or logo is included. |
| Example film narration/music | Synthetic narration generated using Kokoro; the quiet instrumental bed is generated by prepare.py. No commercial music track is included. |

## Installed or downloaded at runtime, not bundled

| Component | Upstream reference |
|---|---|
| Kokoro inference / model | [Inference library](https://github.com/hexgrad/kokoro), [Kokoro-82M model card](https://huggingface.co/hexgrad/Kokoro-82M), Apache-2.0 as declared upstream |
| Misaki / phonemizer / espeak-ng | [Misaki](https://github.com/hexgrad/misaki), package metadata in requirements.txt, [espeak-ng](https://github.com/espeak-ng/espeak-ng). Some speech dependencies carry copyleft terms; do not relabel them proprietary. |
| faster-whisper / CTranslate2 | [faster-whisper](https://github.com/SYSTRAN/faster-whisper), [CTranslate2](https://github.com/OpenNMT/CTranslate2) |
| Whisper model | Downloaded by faster-whisper; preserve the model provider's terms and provenance in any redistributed model bundle. |
| PyTorch | [PyTorch](https://github.com/pytorch/pytorch); installed in the worker container |
| Playwright / Chromium | [Playwright](https://github.com/microsoft/playwright); browser downloaded at installation, with its own third-party notices |
| FFmpeg / libx264 | Distribution-provided binaries; licensing depends on build options. See [FFmpeg legal page](https://ffmpeg.org/legal.html). Binaries are not shipped in this source kit. |
| Vast CLI | [vast-ai/vast-cli](https://github.com/vast-ai/vast-cli), installed by setup-host.sh |
| Python and Node packages | Explicit top-level versions in requirements.txt and package-lock.json; transitive components retain their own terms |

This inventory describes the shipped source kit. Repackaging it as a binary application, container image or bundled model installer changes what is redistributed and requires a fresh review of those included components. Original-kit commercial terms remain the owner's decision in LICENSE / SELLER-NOTES.md.

## Cyber edition artwork

Audio displays, network activity and verification diagrams are original illustrative Canvas/SVG artwork. FTC pages are used as factual sources for the demo; no FTC logo, third-party voice recording or personal data is included.

## JetBrains Mono

Terminal typography uses the unmodified JetBrains Mono Regular font from the official [JetBrains Mono repository](https://github.com/JetBrains/JetBrainsMono), retrieved 9 September 2026. Font: engine/assets/mono.ttf. Its SIL Open Font License 1.1 and copyright notice are included verbatim in engine/assets/mono-LICENSE.txt. Manrope remains bundled for the other palettes.
