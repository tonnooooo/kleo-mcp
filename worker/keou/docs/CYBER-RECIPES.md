# Topic recipes for the assistant

These are starting briefs, not pre-verified scripts or claims. Find up-to-date primary sources for the selected subject.

| Topic | Hook direction | Useful compositions / motion |
|---|---|---|
| AI voice impersonation | Would you trust a familiar-sounding urgent call? | voice-signal → ai-network → data-flow |
| Social engineering | What turns an ordinary message into pressure? | compare → data-flow → steps |
| Password reuse | Why can one breached account affect another? | network hero → compare → steps |
| Multi-factor authentication | What does the extra check actually verify? | data-flow with custom labels → list |
| AI model inputs/outputs | What happens between a prompt and a response? | ai-network → quote → compare |
| Suspicious links | What should you verify before following a request? | data-flow → compare → steps |
| Security alerts | What separates a signal from a confirmed incident? | metric with sourced data → compare → list |
| Defensive monitoring | How does information reach an analyst? | data-flow → ai-network only if an actual AI component is relevant |

Use the technical palette, exact-source narration, original assets and visible internal movement. Do not invent percentages to fill metric scenes. A list or comparison is preferable when no meaningful quantitative fact is available.

For technical tutorials, match the claimed behavior to the actual documented software/version and the user's legitimate environment. This template itself executes no hacking tools.
