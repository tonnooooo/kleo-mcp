# Cyber style — terminal edition

The default is `style: terminal`: black and phosphor green, JetBrains Mono, terminal frames, line numbers, typed display code and a blinking cursor. Use [CYBER-STYLE.md](CYBER-STYLE.md) for the exact controls and examples.

Keep one clear idea per scene. Titles stay readable while the terminal code and native diagrams move. Prefer short, relevant code over dense walls of text. Use the existing eight compositions and the measured narration/caption timing. Animate internal objects when the subject calls for it, and count important values up to an exact final number.

The `editorial`, `technical` and `illustrated` palettes remain optional, using Manrope. The included French and galaxy films show the original editorial foundation; their palette does not override the terminal default in this edition.

Portrait 1080 × 1920 at 60 fps is the qualified full-film output. Both aspect ratios receive browser layout checks. Keep captions within two lines, preserve reading space and inspect actual scene frames. Bound checks complement creative review; they do not measure audience retention.

New projects use the cyber example. Change its script, sources, diagrams, labels and terminal_lines to fit the subject. Displayed code is illustrative and is never executed. Credit external assets and distinguish schematic visuals from actual measurements.
