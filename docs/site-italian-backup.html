Come funziona

Nessuna app da imparare. Un URL, poi parli.

Kleo non ha un'interfaccia sua: vive dentro l'assistente che usi già. I tempi qui sotto sono quelli reali di uno Short da 45 secondi.

00:00

Collega l'URL

Incolli l'indirizzo di Kleo nei connettori di Claude o ChatGPT. Niente da installare, niente chiavi da copiare: fai l'accesso una volta.

00:20

Chiedi il video

Lo descrivi come a un montatore: tema, durata, formato, voce, tono. L'assistente sceglie il template e compila i parametri per te.

00:25 → 25:00

Kleo lavora

Scrive lo script, genera la voce, gira le clip, monta, poi porta tutto a 3840×2160 a 60 fps. La GPU si accende solo per il tuo render.

25:00

Ricevi il link

MP4, sottotitoli e miniatura. Nel frattempo puoi chiedere "a che punto è?" o farti avvisare via email quando è pronto.

Template

Dieci formati che su YouTube funzionano già.

Ogni template è una ricetta di montaggio: ritmo, grafica, sottotitoli, musica. Tu porti l'idea; il tuo assistente sceglie il template e Kleo lo esegue. Gli schizzi mostrano la struttura dell'inquadratura.

I tempi di render sono stime su una singola RTX 4090 in 4K a 60 fps. Con la coda prioritaria del piano Studio i video lunghi girano su più GPU in parallelo.

Dietro le quinte

Cinque tracce, una GPU accesa solo quando serve.

Un video di Kleo è una pipeline a tracce, come una timeline di montaggio. Ogni traccia usa lo strumento migliore per quel lavoro, e le clip si generano in parallelo.

  • Script. Un modello linguistico scrive hook, scaletta e testo parlato dal tuo prompt, nel tono del template.
  • Voce. Sintesi vocale naturale in italiano o inglese; le pause dettano il ritmo del montaggio.
  • Clip. Modelli video aperti generano le inquadrature descritte nello script, una per scena.
  • Montaggio. Tagli sulla voce, sottotitoli animati, musica, titoli e transizioni del template.
  • Finitura. Upscale a 3840×2160 e interpolazione a 60 fps, poi codifica H.265 pronta per YouTube.

Connetti

Un indirizzo, qualsiasi assistente.

Kleo parla il Model Context Protocol su Streamable HTTP con accesso OAuth: lo stesso indirizzo vale per tutti i client. Scegli il tuo.

Claude, app e web

Indirizzo del server https://mcp.kleo.ai/mcp
  1. Apri Impostazioni → Connettori e scegli Aggiungi connettore personalizzato.
  2. Nome Kleo, incolla l'indirizzo qui sopra e conferma. Si apre la pagina di accesso di Kleo: entra una volta.
  3. In una nuova chat attiva Kleo dal menu degli strumenti e chiedi: "Fammi uno Short di 45 secondi su…".

Funziona su tutti i piani Claude; il piano gratuito ammette un connettore personalizzato.

ChatGPT

Indirizzo del server https://mcp.kleo.ai/mcp
  1. Apri Impostazioni → Sicurezza e accesso e attiva la Modalità sviluppatore.
  2. In Connettori scegli Crea: nome Kleo, incolla l'indirizzo, accesso OAuth, salva.
  3. In chat, dal menu +, attiva Kleo e chiedi il video. ChatGPT chiede conferma prima di avviare un render.

Richiede ChatGPT Plus, Pro, Business o Enterprise.

Grok

Indirizzo del server https://mcp.kleo.ai/mcp
  1. Su grok.com o nell'app apri Connectors e scegli New connector → Custom.
  2. Nome Kleo, incolla l'indirizzo e fai l'accesso quando te lo chiede.
  3. In chat attiva Kleo tra i connettori e chiedi il video.

Claude Code

# aggiunge Kleo come server MCP remoto claude mcp add --transport http kleo https://mcp.kleo.ai/mcp # poi, nella sessione: /mcp → Kleo → Authenticate
  1. Esegui il comando qui sopra una volta per progetto, o aggiungi --scope user per averlo ovunque.
  2. Chiedi in sessione: "Usa kleo per un video di 5 minuti sulla storia del caffè, 16:9". Claude Code interroga lo stato finché non è pronto.

Cursor

Crea o modifica .cursor/mcp.json nel progetto, oppure ~/.cursor/mcp.json per tutti i progetti.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleo.ai/mcp" } } }
  1. Salva: Cursor mostra Kleo in Settings → MCP e apre l'accesso OAuth al primo uso.

VS Code, Windsurf, Gemini CLI, agenti tuoi

Kleo è un server MCP standard su trasporto Streamable HTTP con OAuth 2.1. Qualsiasi client compatibile si collega con la stessa configurazione.

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleo.ai/mcp" } } }
  1. Gemini CLI: gemini mcp add --transport http kleo https://mcp.kleo.ai/mcp.
  2. App Gemini: Impostazioni → App collegate → App personalizzate e incolla l'indirizzo (oggi richiede Google AI Pro o Ultra).
  3. Per un agente tuo: usa un SDK MCP (Python o TypeScript), trasporto HTTP, e gestisci il flusso OAuth una volta.

Domande frequenti

Le cose che chiedono tutti.

Che cos'è un MCP e perché mi serve?

Il Model Context Protocol è lo standard con cui gli assistenti come Claude e ChatGPT usano strumenti esterni. Kleo è uno di questi strumenti: una volta collegato, il tuo assistente sa creare video, esattamente come sa cercare sul web.

Devo installare qualcosa?

No. Incolli un indirizzo nei connettori del tuo assistente e fai l'accesso una volta. Non ci sono programmi, plugin o chiavi da gestire.

Quanto ci mette?

Uno Short in 4K a 60 fps chiude in 15–30 minuti, un video da 5 minuti in 45–70. La chat non resta bloccata: chiedi lo stato quando vuoi, oppure fatti avvisare via email quando il link è pronto.

Che qualità esce?

MP4 a 3840×2160 e 60 fps in H.265 o H.264, con sottotitoli .srt separati e una miniatura. Sono file pronti per il caricamento su YouTube, senza filigrana.

Posso usare la mia voce, il mio logo, le mie clip?

Con il piano Studio sì: carichi gli asset dalla chat e i template li usano al posto di quelli generati. La clonazione della voce richiede il tuo consenso registrato.

Di chi è il video?

Tuo. Puoi pubblicarlo, monetizzarlo e modificarlo. Kleo conserva i file per 7 giorni per permetterti di scaricarli, poi li cancella.

Quali modelli usate?

Modelli aperti per video e immagini, sintesi vocale neurale, upscaling e interpolazione dei fotogrammi. I tuoi prompt e i tuoi file non vengono usati per addestrare nulla.

Funziona con Grok o con l'app Gemini?

Sì. Grok accetta connettori personalizzati da grok.com e dall'app; l'app Gemini li accetta con Google AI Pro o Ultra, e Gemini CLI ovunque. Claude, ChatGPT, Claude Code, Cursor, VS Code e Windsurf usano lo stesso indirizzo.
